# 类名、文件路径、控件索引

更新时间：2026-06-01

## 1. 类名索引

| 类名 | 文件 | 说明 |
| --- | --- | --- |
| `AutoCadGui` | `auto_cad_gui/AutoCadGui.h` | 主窗口和 CAD 页面 |
| `AntButton` | `auto_cad_gui/AntButton.h` | 自定义按钮 |
| `AntDesignStyle` | `auto_cad_gui/AntDesignStyle.h` | 样式工具 |
| `AnimatedProgressWidget` | `auto_cad_gui/AnimatedProgressWidget.h` | 进度控件 |
| `SvgIcon` | `auto_cad_gui/SvgIcon.h` | SVG 图标 |

## 2. 文件路径索引

| 路径 | 说明 |
| --- | --- |
| `auto_cad_gui/AutoCadGui.cpp` | 页面构建、信号槽、后端调用 |
| `auto_cad_gui/AutoCadGui.h` | 主窗口成员和接口 |
| `auto_cad_gui/AntDesignStyle.cpp` | 全局样式 |
| `auto_cad_gui/auto_cad_gui.vcxproj` | Qt GUI 工程 |
| `draw_cad/draw_cad.vcxproj` | CAD 后端工程 |
| `draw_cad.sln` | 主解决方案 |

## 3. 控件索引

| 控件类别 | 用途 |
| --- | --- |
| CAD 导航按钮 | 激活 CAD 页面 |
| 文件库导航按钮 | 保留入口样式 |
| 路径输入框 | 展示 Excel、DXF 和输出路径 |
| 浏览按钮 | 触发文件或目录选择 |
| 生成按钮 | 启动 `draw_cad.exe` |
| 进度控件 | 展示生成状态 |
| 日志区域 | 展示后端输出 |

## 4. 依赖索引

| 项 | 当前值 |
| --- | --- |
| Qt 模块 | `core;gui;widgets` |
| 后端程序 | `draw_cad.exe` |
| 默认构建配置 | `Debug|x64` |

## 5. 迁出索引

标书生成、AI 设置、AI 解析和相关控件已经从 `auto_cad_gui` 移除，对应代码和文档由独立 `tender_ai_backend` 项目维护。
