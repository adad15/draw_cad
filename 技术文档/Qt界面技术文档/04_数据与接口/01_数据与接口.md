# 数据与接口

更新时间：2026-06-01

## 1. GUI 数据流

| 数据 | 来源 | 去向 | 说明 |
| --- | --- | --- | --- |
| 病害 Excel 路径 | 文件选择框 | `draw_cad.exe` 参数 | 主输入 |
| 板长 Excel 路径 | 文件选择框 | `draw_cad.exe` 参数 | 辅助输入 |
| 病害图例 DXF 路径 | 文件选择框 | `draw_cad.exe` 参数 | 符号输入 |
| 输出路径/目录 | 文件或目录选择框 | `draw_cad.exe` 参数 | 输出位置 |
| CAD 生成选项 | GUI 控件状态 | `draw_cad.exe` 参数 | 控制绘图行为 |
| 后端日志 | `QProcess` 标准输出/错误 | GUI 日志区 | 运行反馈 |
| 退出码 | `QProcess::finished` | GUI 状态 | 判断成功或失败 |

## 2. 后端接口

| 接口 | 调用方 | 说明 |
| --- | --- | --- |
| `draw_cad.exe` | `AutoCadGui` | 当前唯一 CAD 后端入口 |
| 标准输出 | `AutoCadGui` | 进度和普通日志 |
| 标准错误 | `AutoCadGui` | 错误和异常信息 |
| 输出 DXF | 用户/GUI | 最终 CAD 成果 |

## 3. 本地文件接口

GUI 只负责收集路径，不直接解析 Excel 或 DXF。解析和绘制由 `draw_cad.exe` 完成。

| 文件 | 读写 | 处理方 |
| --- | --- | --- |
| 外观病害 Excel | 读 | 后端 |
| 板长 Excel | 读 | 后端 |
| 病害图例 DXF | 读 | 后端 |
| 输出 DXF | 写 | 后端 |
| 运行日志文本 | 读/展示 | GUI |

## 4. 无网络接口

当前 GUI 不发起网络请求，不维护 API Key，不保存 AI 配置。

## 5. 维护注意

1. 修改后端参数时，同步修改 GUI 参数组装和后端 API 文档。
2. 修改输出路径策略时，同步修改异常处理、部署说明和测试脚本。
3. 标书/AI 数据流已经迁出到独立项目，不在本 GUI 文档维护。
