# 公共组件与样式

更新时间：2026-06-01

## 1. 常用组件

| 组件或函数 | 当前用途 | 说明 |
| --- | --- | --- |
| `AntButton` | 页面主操作和次操作按钮 | 统一按钮视觉状态 |
| `AnimatedProgressWidget` | CAD 生成进度 | 展示运行中状态 |
| `SvgIcon` | 导航或按钮图标 | 渲染 SVG 图标 |
| `createBodyText()` | 页面说明或状态文字 | 统一正文文本样式 |
| `createPathRow()` | 文件路径输入行 | 路径输入框 + 浏览按钮 |
| `createGenerationCheckRow()` | CAD 生成选项 | 勾选项行 |

部分早期通用 helper 仍可能保留在源码中，后续新增 CAD 界面时优先复用当前 CAD 页面已经使用的构造方式。

## 2. 按钮风格

| 类型 | 用途 |
| --- | --- |
| Primary | 生成 CAD、确认类动作 |
| Default/Secondary | 浏览、打开、取消类动作 |
| Text/Ghost | 轻量导航或辅助动作 |

按钮文案应短，状态变化通过 enabled、loading、进度文本和日志共同表达。

## 3. 输入控件

| 类型 | 用途 |
| --- | --- |
| 路径输入框 | 展示用户选择的 Excel、DXF 和输出路径 |
| 浏览按钮 | 打开 `QFileDialog` |
| 勾选项 | 控制是否生成特定 CAD 内容 |
| 文本状态 | 展示当前进程状态或错误 |

## 4. 样式维护

1. 新增控件尽量设置稳定 `objectName`，便于 QSS 管理。
2. 样式优先放在 `AntDesignStyle` 或集中 QSS 中。
3. CAD 页面内部避免重复堆叠卡片；区域层级保持清晰。
4. 删除页面时同步清理未使用的样式选择器。
