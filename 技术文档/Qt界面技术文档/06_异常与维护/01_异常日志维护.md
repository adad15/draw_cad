# 异常日志维护

更新时间：2026-06-01

## 1. 常见异常

| 场景 | 表现 | 处理方式 |
| --- | --- | --- |
| 后端程序不存在 | 生成无法启动 | 提示检查 `draw_cad.exe` 路径或构建产物 |
| 输入文件不存在 | 校验失败或后端报错 | 在 GUI 中提示具体路径 |
| 输出目录不可写 | 后端返回失败 | 提示更换输出位置 |
| Excel 格式不符合预期 | 后端输出错误 | 日志展示解析失败原因 |
| DXF 图例异常 | 后端输出错误 | 提示检查图例文件 |
| 进程异常退出 | 非零退出码 | 展示标准错误和退出码 |

## 2. 日志来源

| 来源 | 内容 |
| --- | --- |
| GUI 状态文本 | 当前步骤、成功或失败摘要 |
| GUI 日志区 | 后端标准输出和标准错误 |
| 后端退出码 | 成功或失败判断 |
| 输出目录 | 生成的 DXF 或残留中间文件 |

## 3. 排查顺序

1. 确认 `draw_cad.exe` 已成功构建。
2. 确认 GUI 传入的 Excel、DXF 和输出路径存在且可访问。
3. 查看 GUI 日志区中的后端输出。
4. 直接在命令行运行 `draw_cad.exe` 复现问题。
5. 必要时检查中间 JSON 和输出 DXF。

## 4. 维护注意

1. 后端错误应保留足够上下文，例如文件路径、阶段和失败原因。
2. GUI 不应吞掉标准错误。
3. 进程结束后无论成功失败都要恢复按钮状态。
4. 标书/AI 诊断日志不属于当前 `auto_cad_gui` 维护范围。
