# Qt 界面文档结构说明

更新时间：2026-06-01

## 1. 当前范围

本文档只覆盖 `auto_cad_gui/` 中仍保留的 CAD 绘制前端。界面当前承担本地 CAD 生成工作台职责，通过 `QProcess` 调用 `draw_cad.exe`。

| 范围 | 当前状态 |
| --- | --- |
| CAD 生成页 | 保留 |
| 文件库导航按钮 | 保留为导航占位/入口样式 |
| 标书生成页 | 已从 `auto_cad` 移除 |
| AI 设置页 | 已从 `auto_cad` 移除 |

## 2. 文档来源

| 来源 | 用途 |
| --- | --- |
| `auto_cad_gui/AutoCadGui.*` | 主窗口、页面构建、信号槽和后端进程调用 |
| `auto_cad_gui/AntDesignStyle.*` | 主题色、按钮、卡片、输入框和滚动条样式 |
| `auto_cad_gui/AntButton.*` | 自定义按钮控件 |
| `auto_cad_gui/AnimatedProgressWidget.*` | 进度展示控件 |
| `auto_cad_gui/SvgIcon.*` | SVG 图标渲染 |
| `auto_cad_gui/WinQtCompat.h` | Windows/Qt 兼容处理 |

## 3. 阅读顺序

| 目标 | 建议阅读 | 说明 |
| --- | --- | --- |
| 快速了解 GUI | `01_系统功能与工程结构.md` | 当前页面、工程结构和依赖 |
| 修改主界面 | `../01_界面功能模块/01_主窗口与CAD生成模块.md` | 布局、CAD 页面和导航 |
| 修改公共样式 | `../02_公共界面组件/01_公共组件与样式.md`、`../05_样式与资源/01_QSS样式与资源.md` | 控件和 QSS 约定 |
| 修改交互 | `../03_信号槽与交互逻辑/01_信号槽与交互逻辑.md` | 信号槽、文件选择、生成按钮 |
| 修改数据流 | `../04_数据与接口/01_数据与接口.md` | GUI 与后端的数据边界 |

## 5. 同步规则

1. 新增页面或导航项后，同步更新主窗口、信号槽、数据接口和索引。
2. 修改控件 `objectName` 后，同步更新 QSS 文档。
3. 修改 `draw_cad.exe` 调用参数后，同时更新后端 API 文档。
4. 标书/AI 页面相关文档在 `auto_cad` 中不再维护。
