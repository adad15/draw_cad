# 环境构建部署

更新时间：2026-06-01

## 1. 构建环境

| 项 | 当前要求 |
| --- | --- |
| 操作系统 | Windows |
| IDE/编译器 | Visual Studio 2022 / MSBuild |
| 平台 | x64 |
| Qt 模块 | `core;gui;widgets` |
| 解决方案 | `draw_cad.sln` |

## 2. 解决方案结构

```text
draw_cad.sln
├── draw_cad
└── auto_cad_gui
```

`auto_cad_gui` 依赖 `draw_cad` 的构建产物。标书/AI 后端不在该解决方案中。

## 3. 推荐构建命令

```powershell
& "D:\vs2022\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" draw_cad.sln /p:Configuration=Debug /p:Platform=x64 /m
```

成功后通常生成：

| 产物 | 说明 |
| --- | --- |
| `x64/Debug/draw_cad.exe` | CAD 绘图后端 |
| `x64/Debug/auto_cad_gui.exe` | CAD Qt 前端 |

## 4. 运行方式

| 方式 | 说明 |
| --- | --- |
| 启动 `auto_cad_gui.exe` | 推荐给最终用户 |
| 直接启动 `draw_cad.exe` | 推荐给调试、脚本和回归验证 |

## 5. 部署注意

1. Qt 运行时 DLL 需要随 GUI 一起部署。
2. `draw_cad.exe` 应与 GUI 可发现路径保持一致。
3. 输入 Excel、图例 DXF 和输出目录需要有对应读写权限。
4. 第三方库 DLL 或数据文件缺失时，优先检查可执行文件目录和运行工作目录。
