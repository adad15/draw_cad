# 安全权限说明

更新时间：2026-06-01

## 1. 权限范围

`auto_cad` 当前是本地桌面和命令行程序，不提供网络服务。主要权限来自文件读取和文件写入。

| 对象 | 权限 | 说明 |
| --- | --- | --- |
| 外观病害 Excel | 读 | 用户选择的输入文件 |
| 板长 Excel | 读 | 用户选择的输入文件 |
| 病害图例 DXF | 读 | 用户选择或默认图例文件 |
| 输出 DXF | 写 | `Drawing1.dxf` 或用户指定输出位置 |
| 批量输出目录 | 写 | 批量绘图成果 |
| 中间 JSON/日志文本 | 读写 | 调试和运行过程产物 |

## 2. 敏感数据

当前 `auto_cad` 不保存 API Key、账号密码或联网凭据。需要注意的数据主要是工程文件路径和用户提供的病害资料内容。

## 3. 输入风险

| 风险 | 建议 |
| --- | --- |
| Excel 内容格式异常 | 在后端解析阶段做字段缺失、类型转换和空值检查 |
| DXF 图例异常 | 读取失败时返回明确错误，不继续生成不完整成果 |
| 输出目录不可写 | GUI 在生成前提示，后端返回非零退出码 |
| 路径包含空格或中文 | GUI 调用进程时保持参数分离，不拼接成单个命令字符串 |

## 4. 文件覆盖

默认输出文件名可能覆盖旧的 `Drawing1.dxf`。需要批量保存或留存历史时，应使用独立输出目录。

## 5. 迁出说明

标书/AI 后端涉及的 API Key、模型服务、提示词和标书文档安全风险由独立 `tender_ai_backend` 项目维护。
