# 命令行与服务接口

更新时间：2026-06-01

## 1. 后端入口

当前 `auto_cad` 后端只有本地命令行入口：

```text
draw_cad.exe
```

GUI 通过 `QProcess` 启动该程序。项目没有 HTTP API、RPC 服务或数据库接口。

## 2. 调用方

| 调用方 | 调用方式 | 说明 |
| --- | --- | --- |
| `auto_cad_gui` | `QProcess` | 图形化工作流的默认调用方式 |
| PowerShell/批处理 | 直接启动 `draw_cad.exe` | 用于调试、自动化或回归验证 |

## 3. 输入输出约定

| 类型 | 内容 |
| --- | --- |
| 输入文件 | 外观病害 Excel、板长 Excel、病害图例 DXF |
| 输出文件 | `Drawing1.dxf` 或批量输出目录中的 DXF |
| 过程信息 | 标准输出、标准错误、进程退出码 |
| 错误反馈 | 非零退出码或输出中的错误文本，由 GUI 转成状态提示 |

## 4. 主要后端服务边界

| 模块 | 职责 | 对外表现 |
| --- | --- | --- |
| 参数和流程编排 | 校验输入路径、组织读取和绘制步骤 | 进程启动、退出码 |
| Excel 读取 | 解析病害和板长数据 | 中间数据结构或 JSON |
| DXF 读写 | 读取图例、写出 CAD 文件 | 输出 DXF |

## 5. 接口变更注意

1. 修改 `draw_cad.exe` 参数或输出格式后，同步更新 GUI 调用和本文档。
2. 修改默认输出文件名或目录后，同步更新部署、测试和安全说明。
3. 标书/AI 后端接口属于独立 `tender_ai_backend` 项目，不在此处维护。
