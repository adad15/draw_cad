# 核心业务模块

## 1. DXF 符号提取模块

### 模块功能

从 `Drawing1.dxf` 中读取病害符号块，将符号几何、样式、包围盒、缩放模式导出为 `symbols.json`。

### 业务边界

负责：

- 读取 DXF 块定义。
- 只采集名称前缀符合 `SYM_` 的块。
- 把线段、多段线、圆弧、圆等转换为内部图元。
- 生成符号 JSON。

不负责：

- 判断 Excel 病害应使用哪个符号。
- 在最终平面图中布局病害。

### 核心类与文件

| 类/结构 | 文件 | 说明 |
|---|---|---|
| `dxf_to_json` | `draw_cad/dxf_to_json.*` | 入口转换器 |
| `DxfSymbolCollector` | `draw_cad/DxfSymbolCollector.*` | libdxfrw 回调收集器 |
| `SymbolClassifier` | `draw_cad/SymbolClassifier.*` | 块名到符号类型、缩放模式的推断 |
| `SymbolGeometry` | `draw_cad/SymbolGeometry.*` | 弧线离散、bulge 多段线、包围盒和归一化 |
| `SymbolJsonWriter` | `draw_cad/SymbolJsonWriter.*` | 写出 `symbols.json` |
| `TuXing`、`TuYuan` | `draw_cad/dxf_to_json.h` | 符号和图元中间结构 |

### 测试要点

- `symbols.json` 中存在 `meta.unit=m` 和 `symbols` 数组。
- `LongitudinalCrack` 的 `params.scale_mode` 为 `stretch_x`。
- 斜向裂缝不应被标记为 `stretch_x`。

## 2. Excel 与 JSON 导出模块

### 模块功能

把病害工作表和板长 Excel 转换为绘图模块需要的结构化 JSON。

### 业务边界

负责：

- `InspectionTableReader` 按表头读取病害业务列。
- `DiseaseReportJsonExporter` 输出病害记录。
- `BoardLengthJsonExporter` 输出板号长度记录。

不负责：

- DXF 布局。
- 病害符号几何绘制。

### 病害报告导出

入口：

```cpp
DiseaseReportJsonExporter::run(input_xlsx, output_json, options)
```

核心规则：

1. 默认 `header_row=1`。
2. 默认 `project_name_filter` 为空时使用“衬砌”。
3. `桩号` 和 `检测日期` 在当前导出中作为可选列处理。
4. `judgement` 可严格解析为 0 时标记 `judgement_is_zero=true`，但记录仍写入 JSON。
5. 病害描述中解析“距板端”“长度为”“宽度为”“面积为”。

### 板长导出

入口：

```cpp
BoardLengthJsonExporter::run(input_xlsx, output_json, options)
```

核心规则：

1. 默认 `header_row=2`。
2. 从第 3 行开始读取。
3. 同时读取 `A:B` 和 `D:E` 两组列。
4. `length_m` 必须是严格正数。
5. 板号按数字优先、数字升序、文本升序排序。

### 异常处理

| 场景 | 处理 |
|---|---|
| 必需表头缺失 | `InspectionTableReader::ReadResult.errors` |
| 板长为空、非数字、板号重复 | 写入 warnings，不一定阻断 |
| 输出 JSON 打不开 | 返回模块错误码 |
| Excel 打开失败 | 捕获异常并返回失败结果 |

## 3. 衬砌平面图 DXF 生成模块

### 模块功能

读取病害 JSON、板长 JSON 和符号 JSON，生成衬砌平面图 DXF。

入口：

```cpp
LiningPlanDxfWriter::run(disease_report_json, board_lengths_json, output_dxf, options)
```

### 核心流程

1. 校验 `LiningPlanDxfWriter::Options`。
2. 读取 `disease_report.json.records`。
3. 读取 `board_lengths.json.records`。
4. 读取 `symbols.json.symbols`。
5. 根据病害板号和纵向跨板长度补充需要绘制的板号。
6. 每 5 块板生成一个平面图面板。
7. 绘制外框、横向分区、板号、分割线、病害符号和文字。
8. 使用 libdxfrw 写出 DXF。

### 绘图规则

| 规则 | 当前实现 |
|---|---|
| 每块图板数 | `slabs_per_panel = 5` |
| 板宽 | 来自 `board_lengths.json.records[*].length_m` |
| 缺失板长 | 使用 `default_slab_length_m=8.0` 并输出 warning |
| 相邻板号 | 使用直线分割 |
| 非相邻板号 | 主体区域使用双折线断开符号 |
| 中文文字 | 使用 `CN_TEXT` + `simsun.ttc` + `\U+XXXX` 转义 |
| 图层 | `FRAME`、`BREAK`、`DISEASE`、`TEXT` |

### 病害符号映射

`symbolIdForDisease()` 优先使用 `check_item`，`defect_desc` 只作为兜底。维护时不要让伴随描述覆盖主病害类型。

| 病害 | 符号 |
|---|---|
| 纵向裂缝 | `crack_long` |
| 环向裂缝、横向裂缝 | `crack_trans` |
| 斜向裂缝 | `crack_diag` |
| 网状裂缝、龟裂 | `crack_alligator` |
| 渗水印迹 | `seepage` |
| 露筋 | `rebar` |
| 破损、涂层脱落 | `damage` |

### 维护注意事项

1. `LiningPlanDxfWriter.cpp` 是当前最大单文件，后续可按 JSON 读取、病害映射、位置映射、避让布局、DXF 写入拆分。
2. `diseaseLocationBand()` 的同义词规则需要显式维护，例如“左侧墙”“左边墙”“左侧边墙”都应落到左侧边墙区域。
3. `斜向裂缝` 不按 `length` 缩放，只显示长度文字。
4. 病害图形必须尽量避开横向分隔线；文字说明允许压在线上。
5. 跨板纵向病害同一面板内应合并为连续图形，避免 022/023 被画成两条断裂线。
