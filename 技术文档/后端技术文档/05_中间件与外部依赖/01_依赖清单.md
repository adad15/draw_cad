# 依赖清单

更新时间：2026-06-01

## 1. 当前依赖

| 依赖 | 类型 | 使用位置 | 用途 |
| --- | --- | --- | --- |
| Qt Core | Qt 模块 | `auto_cad_gui` | 进程、路径、字符串、时间等基础能力 |
| Qt Gui | Qt 模块 | `auto_cad_gui` | 图标、字体、颜色等 GUI 能力 |
| Qt Widgets | Qt 模块 | `auto_cad_gui` | 主窗口、按钮、输入框、布局和弹窗 |
| OpenXLSX | C++ 库 | `draw_cad` | 读取 `.xlsx` 输入 |
| libdxfrw / DXF 相关库 | C++ 库 | `draw_cad` | 读取图例 DXF、写出结果 DXF |
| nlohmann/json | C++ 头文件库 | `draw_cad` | 读写中间 JSON |
| libiconv | C/C++ 库 | `draw_cad` | 编码转换 |
| Visual Studio/MSBuild | 构建工具 | 解决方案构建 | 编译 C++ 和 Qt 项目 |

## 2. Qt 模块边界

`auto_cad_gui.vcxproj` 当前使用：

```text
core;gui;widgets
```

项目不再依赖 Qt Network。

## 3. 外部接口

当前 `auto_cad` 没有外部网络接口。所有业务输入输出均来自本地文件系统：

| 方向 | 内容 |
| --- | --- |
| 读取 | Excel、DXF、配置路径 |
| 写入 | DXF、批量输出目录、运行中间文件 |

## 4. 迁出依赖

OpenAI 兼容接口、AI 配置、提示词技能包、标书生成和 Qt Network 相关依赖已经迁到同级 `tender_ai_backend` 项目。
