# 测试说明

更新时间：2026-06-01

## 1. 当前保留测试

| 脚本 | 类型 | 说明 |
| --- | --- | --- |
| `tests/check_cad_datasource_ui.ps1` | 静态结构回归 | 验证 GUI CAD 数据源页面、工程引用和 CAD-only 边界 |
| `tests/check_longitudinal_cross_slab.ps1` | 静态逻辑回归 | 验证纵向跨板病害绘制相关代码结构 |

## 2. 推荐执行

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\check_cad_datasource_ui.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tests\check_longitudinal_cross_slab.ps1
```

构建回归：

```powershell
& "D:\vs2022\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" draw_cad.sln /p:Configuration=Debug /p:Platform=x64 /m
```

## 3. 回归重点

| 改动类型 | 重点检查 |
| --- | --- |
| GUI CAD 页面 | 文件选择、参数输入、进度状态、后端进程调用 |
| 后端参数 | GUI 调用参数、默认输出路径、错误返回 |
| Excel 解析 | 空值、列名变化、路径不存在、数据类型转换 |
| DXF 生成 | 图层、图块、文字、里程、环号、跨板病害 |
| 工程文件 | `.vcxproj`、`.filters`、`draw_cad.sln` 是否同步 |

## 4. 质量缺口

| 缺口 | 建议 |
| --- | --- |
| 缺少端到端样例测试 | 增加最小 Excel + DXF 输入，校验输出 DXF 存在和关键文本 |
| 缺少进程调用测试 | 对 GUI 的 `QProcess` 参数组织增加轻量检查 |
| 缺少异常样例 | 增加输入文件缺失、输出目录不可写、Excel 列缺失的回归样例 |

## 5. 迁出说明

标书/AI 后端测试已经移动到独立 `tender_ai_backend` 项目，不再由 `auto_cad/tests` 维护。
