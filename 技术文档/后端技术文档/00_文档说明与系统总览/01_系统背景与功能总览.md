# 系统背景与功能总览

更新时间：2026-06-01

## 1. 项目定位

`auto_cad` 的目标是把隧道外观病害 Excel、板长 Excel 和病害符号 DXF 自动转换为带病害标注的衬砌平面图 DXF。当前仓库只保留 CAD 绘制相关代码：

| 子系统 | 目录 | 说明 |
| --- | --- | --- |
| CAD 绘图后端 | `draw_cad/` | 解析输入数据，生成 CAD/DXF 输出 |
| CAD Qt 前端 | `auto_cad_gui/` | 提供文件选择、参数输入、执行进度和结果展示 |
| 回归测试 | `tests/` | 静态结构和关键绘图场景检查 |

标书/AI 后端已经迁出到同级 `tender_ai_backend` 项目，`auto_cad` 不再编译、调用或维护该功能。

## 2. 核心业务能力

| 能力 | 当前实现 |
| --- | --- |
| 病害 Excel 读取 | 读取外观病害记录，解析里程、环号、病害类型和尺寸信息 |
| 板长 Excel 读取 | 读取纵向板长数据，为环向位置和排版提供尺寸依据 |
| 病害符号读取 | 读取 `病害图例.dxf`，加载符号块或几何模板 |
| CAD 绘制 | 生成隧道衬砌平面图、边界、里程、环号、病害标注和图例 |
| DXF 输出 | 写出主输出文件 `Drawing1.dxf` 和批量输出目录 |
| GUI 调用后端 | Qt 前端通过 `QProcess` 启动 `draw_cad.exe`，展示进度和错误 |

## 3. 当前不包含的能力

| 能力 | 状态 |
| --- | --- |
| 标书生成 | 已迁出到 `D:\vs2022 code\tender_ai_backend` |
| AI 设置和联网解析 | 已迁出到 `D:\vs2022 code\tender_ai_backend` |
| 原生 DWG 写出 | 当前输出 DXF |
| 数据库服务 | 当前使用文件输入输出，没有数据库 |
| Web API 服务 | 当前提供命令行后端和本地 Qt 前端，没有 HTTP 服务 |

## 4. 主要输入输出

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 病害 Excel | `外观病害1.xlsx` | 主业务输入 |
| 板长 Excel | `隧道板长.xlsx` | 板长和里程计算输入 |
| 图例 DXF | `病害图例.dxf` | 病害符号来源 |
| 输出 DXF | `Drawing1.dxf` | 默认 CAD 输出 |
| 批量输出目录 | `batch_output/` | 批量绘图结果 |

## 5. 用户入口

| 入口 | 用途 |
| --- | --- |
| `auto_cad_gui.exe` | 推荐入口，提供图形化 CAD 生成流程 |
| `draw_cad.exe` | 命令行入口，可被 GUI 或脚本调用 |
