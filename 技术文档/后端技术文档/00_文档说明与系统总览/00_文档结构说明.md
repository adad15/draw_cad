# 后端文档结构说明

更新时间：2026-06-01

## 1. 当前范围

本后端文档只覆盖 `auto_cad` 中的 CAD 绘图后端代码和它与 Qt 前端的调用边界。

| 范围 | 当前状态 |
| --- | --- |
| CAD 绘图后端 | `draw_cad/`，保留 |
| Qt 前端调用 | `auto_cad_gui/` 通过 `QProcess` 调用 `draw_cad.exe` |
| 标书/AI 后端 | 已迁出到同级 `tender_ai_backend` 项目，不在本文档维护 |

## 2. 文档来源

| 来源 | 用途 |
| --- | --- |
| 当前源码 | 以 `draw_cad/`、`auto_cad_gui/`、`tests/`、`draw_cad.sln` 当前状态为准 |
| 旧根目录文档 | 作为历史材料参考，不直接代表当前代码 |
| 验证脚本 | 以 `tests/*.ps1` 中仍保留的 CAD 检查为准 |

## 3. 阅读顺序

| 目标 | 建议阅读 | 说明 |
| --- | --- | --- |
| 快速理解系统 | `01_系统背景与功能总览.md` | 项目目标、边界和核心能力 |
| 理解后端流程 | `../01_系统架构设计/01_总体架构与关键流程.md` | Excel、DXF、JSON 到输出 DXF 的流程 |
| 修改绘图逻辑 | `../02_业务模块设计/01_核心业务模块.md` | CAD 绘制模块、数据读取模块和输出模块 |
| 调用或部署 | `../03_API接口文档/01_命令行与服务接口.md`、`../08_部署与运维/01_环境构建部署.md` | 命令行参数、构建环境和产物 |
| 回归验证 | `../09_测试与质量保障/01_测试说明.md` | 当前保留的 CAD 回归脚本 |

## 5. 同步规则

1. 新增或删除后端源文件后，先确认 `draw_cad.vcxproj` 和 `draw_cad.sln`。
2. 新增输入、输出或中间 JSON 后，同步更新数据模型和安全说明。
3. 修改 GUI 到后端的调用方式后，同时更新命令行接口和 Qt 数据流文档。
4. 标书/AI 相关变更只更新独立 `tender_ai_backend` 项目的文档。
